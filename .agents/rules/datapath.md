### Kernel and userspace ABI

Shared eBPF/`honk-core` constants and `#[repr(C)]` structs in `#![no_std]`; `aya` is non-BPF-only for `Pod` impls. **Layouts and map key sizes must agree**: change types/constants together in [this crate](../../crates/honk-ebpf-common), `honk-ebpf`, and `honk-core` map writers.
Keep `Pod` payloads recursively free of implicit padding; reserved bytes must be explicit fields. Only audited concrete `FlowMapValue` payloads implement `Pod`, and object BTF admission must include the reserved fields without moving existing offsets.

- Change eBPF map layouts, state transitions, marks and statistics keys together in `honk-ebpf-common`, `honk-ebpf`, `honk-core` and their `honk-nfqueue`/`honk-tool` consumers; preserve the `UDP_DECISION_SEQUENCE` ABI and cross-restart token uniqueness.
- Invariants: IPv4 flows are stored as `::ffff:<ipv4>` (network byte order) everywhere; all wire structs are `#[repr(C)]`. `DnsCacheEntry` and `DomainKey` do **not** exist (domain routing uses `DomainRouting`; DNS caching is purely userspace). ABI assertions and focused token/state tests protect the live layouts. Userspace has no `PARAM` static; only the kernel's `Global<DaeParam>` is configured through `EbpfLoader::override_global`.
  Preserve the legacy 12-byte raw-token ABI across cleanup/restart; startup validates without rewriting. At generation boundaries, eBPF stays sticky-exhausted until fenced userspace rotation. Ring events prompt detection; locked periodic reads are the lossless backstop. One synchronous private map-in-map grace barrier drains pre-fence non-sleepable readers; canonical tuple fences exclude new accesses. Rotation requires an empty candidate-through-3 suffix across conn state, handoff, redirect and `RetirementFence.decision_token`, never its operation owner.
  Follow [NFQUEUE terminal ordering and fencing](../../doc/en/design/nfqueue.md#terminal-transitions); preserve partial deletion counts, both operation/release errors and fatal fencing of unresolved ownership. Complete scans end at terminal `ENOENT`, and admitted cleanup must remain joined after warnings.
  `ActivateDirect` is the sole grace-free terminal commit: an in-place `EXIST|F_LOCK` update of frozen `DirectArmed` state that requires both auxiliaries to be absent. `ArmDirect`, `ActivateProxy` and `Block` keep the fence and one grace per batch; never let a reclaim reach an element a pre-fence reader may still hold.
  Preserve backend write lock → correlator cell lock order and drop the backend lock before endpoint kernel handoff. Commit leases and their original deadlines remain owned across caller cancellation.
  `FlowMapValue<T>` adds a native lock at offset 0 and payload at offset 8 to conn/redirect/handoff maps (stored sizes 80/48/80; payloads 72/40/72 bytes). These tuple elements are never replaced or physically deleted by the kernel: Linux can recycle them before an RCU reader ends. Take coherent locked snapshots/projections, compare captured identity during locked mutation, and call no helper under lock except unlock. `flow.rs` and `auxiliary.rs` own these boundaries. Engine snapshots use locked reads; external CLI tuple enumeration requires bucket-protected locked batches without unsafe singleton fallback. `honk-core`'s `ebpf/map_snapshot.rs` owns the one userspace `BPF_MAP_LOOKUP_BATCH` cursor/count traversal for the engine and CLI; adapters keep typing, capability and fallback policy. Validate actual map BTF wrappers; preserve the 12-byte UDP allocator.
  Preserve the shared nonwrapping TCP/UDP incarnation domain, forward-SYN-only publication and accepted-child proof before routing, pinning or cleanup; [TCP ownership](../../doc/en/design/datapath.md#map-inventory) defines the classification rules. Exact native pins belong to each accepted guard, not the tuple's latest occupant, and janitor rechecks them under backend write ownership.
  `honk_tcp_passive` is a required root-cgroup `sock_ops` link; startup and listener publication fail without it, and a legacy flags=0 program already holding that cgroup's slot refuses startup. It acts only on `PASSIVE_ESTABLISHED_CB` for sockets whose netns cookie equals `TCP_DAENS_NETNS_COOKIE` (from `SO_NETNS_COOKIE` of a daens socket; zero disables), takes the ISN as `rcv_nxt - 1`, and under the existing locks validates tuple, ISN, `ORIGINAL_INTERCEPT`, conn/handoff/redirect incarnation agreement and handoff age, but not Active (TC marks Closing on a FIN/RST it can see before, or on, the handshake-completing segment), before one `bpf_sk_storage_get(F_CREATE)` of the complete `TcpSocketBinding`. It always returns 1 and counts storage failure. Keep it stack-only with family-separated `#[inline(never)]` constant-offset ctx reads built from per-word volatile loads (a merged copy of `remote_ip6` failed the 6.12 verifier). TCP ownership needs no kernel BTF, ftrace, `bpf_probe_read*` in mandatory TC programs, or built-in IPv6; external raw BTF stays mandatory at startup (loader target BTF, pname/receive-trace offsets), and receive tracing still needs in-kernel BTF/ftrace and degrades without them. Owned daens disables and verifies cookies, migration and Fast Open; only the absent optional `tcp_syncookies` key is tolerated, never inspection/write/verification failure.
  Failed unpublished UDP claims retain their actual token as `Aborted`, never mutate completed states, and retire matching auxiliaries before conn state. Only actual conn-deletion evidence authorizes [exact endpoint retirement](../../doc/en/design/control-plane.md#tcp-relay-and-conn-state-ownership), including partial progress before an error.
  Stateless auxiliary refresh may overwrite only token/incarnation `0/0`; unknown-peer fallback grants neither renewal nor attribution. Keep NFQUEUE cold reconstruction under backend-owned admission checks; see [datapath ownership](../../doc/en/design/datapath.md#map-inventory).
  Occupancy calibration requires a complete traversal and fresh counters; telemetry failure must not stop sweeping or relax pressure. Cleanup and admission-pressure publication errors remain fatal; [janitor policy](../../doc/en/design/datapath.md#userspace-maintenance-and-accounting) owns cadence and thresholds.

### Runtime invariants

- **Bypass mark:** initialize the process-wide effective `global.so_mark_from_dae` before network I/O (zero means default `0x100`; restart-required; validation rejects `0xc8000000` because daens routes TPROXY-marked listener replies locally). Dials/probes/DNS/bootstrap/HTTP/QUIC sockets and transparent listeners use that exact value. Nonzero direct rule marks use `rule_mark | CLASSIFIED_MARK`, never OR the global value; Linux `ip rule` must mask with `0x3fffffff`. WAN bypass accepts exact configured marks or classified-without-pending marks, not arbitrary bit `0x100`. Clear inherited listener marks on accepted TCP sockets. Non-DNS local-socket probing recognizes honk via `mark == PARAM.dae_socket_mark`; unmarked transparent listeners look like local services. Host-netns `dns.bind` ingress stays unmarked, not an exemption from LAN port-53 policy. Exact configured marks bypass LAN TCP/UDP policy too, including LAN-bound loopback. Bootstrap fallback uses `/etc/hosts` and marked DNS to the first numeric `/etc/resolv.conf` nameserver, never unmarked libc NSS.
- **Anyfrom UDP replies:** never reply from a transparent TPROXY listener; preserve original-destination addressing and keep client-only fallback free of outbound attribution or conn-renewal authority. UDP arriving from `dae0` must not create reverse conn state; see [reply ownership](../../doc/en/design/datapath.md#udp-lifetime-renewal).
- **Netns discipline:** stay in host netns, creating/serving `dns.bind` there. Enter `daens` only via scoped synchronous `daens::with_daens_netns`; **never `.await` inside** because setns is per-thread. Save `/proc/thread-self/ns/net` under a process-wide mutex; restore on every exit; failed restore **aborts**, preventing stranded workers originating dials in daens. Socket creation tests `daens::DAENS_READY` set by `daens::setup_daens_namespace`, never compat bind-mount existence. Unmount only this instance's tmpfs/bind-mount; delete `dae0` by creation-recorded ifindex, leaving same-named replacements alone.
- **Datapath admission:** require all internal hooks, including `dae0_ingress` in WAN-only mode, listener FD publication and receive-loop/NFQUEUE readiness before admission, and close admission before listener teardown. Configured LAN/WAN interfaces are bound lazily: an absent, refused or unattachable one does not gate admission and is visible through the `interface_binding` degradation. Drop only owned TCX links and preserve [pass-through versus mark-owning finality](../../doc/en/design/datapath.md#interface-hook-sets).
- **NFQUEUE readiness and ownership:** ordinary UDP staging and fragmented LAN UDP53 controller/raw delivery require ready queue ownership. Clear readiness, complete the synchronous kernel grace barrier, reclaim Preparing/Pending in fenced batches, then publish a fresh routing descriptor generation. Failed quiescence forbids READY until a complete fence succeeds. `ROUTING_GENERATION_SEQUENCE` is a core-owned single-value persistent pin, separate from unchanged `UDP_DECISION_SEQUENCE`; reserve nonwrapping 20-bit values before publication/fences and preserve across cleanup/restart. Never reset it while host fragment queues may retain old carriers. No recompilation for descriptor-only fences.
- **Fragmented LAN UDP53:** only first fragments needing controller/raw delivery defer to host native reassembly and queue 320; native direct-must/block/exact bypass retain their actions. Disabled/unready queues drop required fragments. DNS queue events use route/generation carriers, never ordinary token cleanup or conn-state. Admission epoch, receipt deadline and generation checks precede confirmed `NF_DROP`; publish DNS/raw work only afterward. Validate UDP checksums with kernel partial-checksum metadata, reject identified bad payloads per packet, and retain fatal queue/envelope/verdict errors. Existing redirect tracking supplies anyfrom replies. TCP fragments are outside this path.
- **Token-checked terminal state:** require token agreement across skb mark, conn state, handoff, redirect track, verdict cell, lease, endpoint/tombstone, backend transition. Direct marked `NF_ACCEPT` follows `ArmDirect`, which requires `Pending` and retains the token through activation; activate only after every verdict succeeds. `ActivateProxy` publishes the final outbound and mark while retaining the provisional redirect track. Armed followers append only verdict guards, discarding payload without slow/endpoint admission. Proxy publishes before canonical dial/send. Stale cleanup fences the exact tuple, waits pre-fence readers, then revalidates; never overwrite/delete newer incarnations.
- **NFQUEUE lifecycle:** fence readiness → quiesce stagers → reject ingress → drain all admitted work, including commits → detach producers → close queue → delete the owned table last; reload retains the joined commit pump. Ownership ambiguity stays fatal/fenced; preserve the allocator pin and the [rollback-safe rotation rule](../../doc/en/design/nfqueue.md#sequence-exhaustion-and-rotation).
- **must/block are final:** a matching configured `must` rule is terminal; Clash mode override never overrides `block` or `must` results.
- **Fail-closed on dead outbounds:** preserve the [health-gating exceptions](../../doc/en/design/datapath.md#outbound-liveness), never introducing an implicit `direct` fallback or letting health bypass selected policy. Selector TCP/UDP must not substitute an unchosen sibling or bypass a chosen empty subgroup; the sole-leaf TCP recovery attempt follows the current Selector path.
  New flows routed to a dead outbound are `TC_ACT_SHOT` on LAN ingress and WAN egress. Only fresh TCP SYN publication is health-gated: established and cached/retransmitted TCP survive health changes, while UDP is gated per packet except native-direct offload and committed token-bound LAN `Proxy` redirects. TCP and UDP port 53 are exempt.
  Ordinary LAN TCP/UDP `:53` evaluates traffic policy even when an exact or wildcard local DNS listener exists; local-socket precedence applies only to non-53 destinations. `must` suppresses sniff-driven rerouting and preserves the selected direct/block/group action, not a blanket bypass. Do not synthesize interface-address routing rules or a replacement kernel allowlist; retain interface observation for topology/ECS/health. Gateway-native routing is [explicit user configuration](../../doc/en/reference/routing.md#explicit-local-rules). Network events clear stale probe cooldowns and schedule immediate checks; other dead nodes stay closed until fresh success verifies recovery.
- **eBPF connectivity pushes are group-OR plus the sole-TCP-leaf exception:** publish OR of reachable leaf states, including explicit nested `final` edges, into every affected ancestor group alive slot, with the last-resort exception above. One dead member must never `TC_ACT_SHOT` an entire multi-leaf group. GroupManager owns nested final resolution; ordinary member lists remain separate from final-aware health, warm and Score reachability. Never substitute an unchosen Selector sibling or bypass a terminal protocol refusal.
- **Internal traffic is never proxied:** own-link `169.254.0.0/16`, `fd00:686f:6e6b::/64`. **Broadcast/multicast passes through eBPF:** `dst_is_special()` (crates/honk-ebpf/src/transport.rs) early-exits L2 broadcast/multicast MAC, 255.255.255.255, 224.0.0.0/4, 0.0.0.0, ff00::/8 in lan_ingress/lan_egress/wan_egress. DHCP/mDNS/SSDP never enter routing/conntrack; otherwise OpenWrt LAN DHCP breaks. Preserve non-DNS LAN local-socket precedence, including the TCP pure-SYN probe skip; destination 53 must not take that early return.
- Reserved outbound indices: `0 Direct | 1 Block | 2+ user groups | 0xFC MustRules | 0xFD ControlPlaneRouting | 0xFE OR | 0xFF AND`.
