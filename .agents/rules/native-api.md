## Native API, observation and logs

Read with: `AGENTS.md` (Technology stack); `configuration.md` (Native API, configuration authority, configuration db) for settings and source administration; `security.md` for credentials, source writes and the state db; `test-locations.md` for the suites.

### Server, limits and embedded UI

Native limits: 64 connections overall, [16 per peer IP](../../doc/en/reference/api.md#native-api), 5s headers, 30s read-idle deadline only while no request is in flight (end of body until response resolves), 30s stalled-write deadline, 5s joined HTTP shutdown; one 1s sampler. Accept errors log and retry (100ms backoff on EMFILE/ENFILE/ENOBUFS/ENOMEM); a failed connection task is logged, not fatal. Flow recorder 1024/64 steps/8 MiB including snapshots, terminal 300s, evicting the oldest ended record before any live one; flow snapshots 8/30s. Node snapshots 8/30s/4 MiB. SSE 512 events/60s/16 clients/64 queue/15s heartbeat; events and logs both resume ready → replay → live. Native catalog group IDs are process-stable; config group UUIDs and `created_at` survive same-name reload, not rename. Per-network Selector and automatic-policy pin/clear, source-owned Group PATCH, synchronous main-source node/provider create/delete and verified-geodata operations are enabled; native runtime_mode and full kernel transparency remain gated. Default-off `native-ui` embeds pinned real doona standard and lite assets without fonts: packaging obtains both distributions pinned in `.github/ci/pins.env` through `ci/fetch-doona.sh`, and `build.rs` embeds `HONK_DOONA_DIR` and its `-lite` sibling, including each edition's notices; no vendored asset tree or runtime fetch. `alive/observations.rs` retains qualified actual probe facts independently of legacy routing liveness; never infer fresh native health from restored/synthetic/derived collections. Config/auth: `.agents/rules/configuration.md`, `.agents/rules/security.md`.
`native_api/server.rs` owns HTTP/sampler shutdown; `auth.rs` owns one tracked blocking credential job and sessions, with storage/request children. Close auth admission before the five-second HTTP grace, then join real KDF/SQLite work even after request cancellation. Signed ready checkpoints remain distinct from evicted event cursors. Catalog snapshots, DNS responses and DNS log pages mask listener-secret display values before bounded serialization, without changing IDs or cursor bindings.

### Observation

Native flow `complete` means source evidence through that flow's executed frontier, not success or global transparency. Preserve actual route/DNS/group/transport/session outcomes and generation/attempt/lookup lineage; never reconstruct kernel execution or historical membership from current state. Capture loss, ambiguity and essential redaction remain explicit partial evidence. Keep recorder snapshots and frozen kernel dictionaries within the shared byte budget. Async observation scopes borrow caller-pinned operations to avoid multiplying future state; preserve cancellation/drop ordering before terminal cleanup, rather than increasing thread stacks or adding per-layer boxes.
Engine-side observation (flows, rules, catalog identity, `DnsRecorder`, `Observation`/owner) lives in `crate::observe`; `native_api` holds only the HTTP projection. Without `native-api`, observation hooks compile as zero-cost inert twins (`observe/inert.rs`). honk-outbound features `flow-observation` and `owned-tasks` are enabled by honk-core `native-api`.
`observe/dns/history.rs` owns bounded client DNS retention inside `DnsRecorder`; `native_api/dns/log.rs` reads a lock-held view for cursor/filter handling, listener-secret masking and JSON projection.
`observe/flows/producer.rs` owns FlowGuard mutations, callbacks and shared selection projection; `observe/flows/record.rs` owns wire models, including DNS inputs; `native_api/flows.rs` only maps them to HTTP. DNS scopes retain lookup/catalog authority rather than becoming a generic projection owner. `native_api/config/http.rs` owns source HTTP adapters; the coordinator awaits durable promotion before advancing its queue.
`native_api/settings.rs` owns independent flow/log/DNS-log demand, stream leases and the existing maintenance/grace transition; passive events alone do not enable diagnostic recording. `control/reload/fingerprint.rs` owns same-name config group identity normalization; `connection_tracker.rs` owns shared close completion. `control/cache.rs::StateTick` retains its join across cancellation and waits beyond the ten-second warning for real blocking maintenance. `mode.rs::DatapathFlagsPublication` participates in the existing reload publication order documented in `doc/en/design/control-plane.md`; no new lock edges are implied. Real-backend `cleanup()` releases its receive-trace fallback before the BPF object, not at backend Drop.
Kernel witness admission uses `DATAPATH_FLAG_TRACE_ENABLED` in the existing composed flags, reconciled by the existing native sampler and terminal shutdown. Convergence is a subsequent tick, not a hard one-second bound; missing pre-enable evidence stays explicit. Preserve admitted operation capture after demand changes and never clear retained sidecars/dictionaries just to turn recording off. `native_api/events.rs` caches one first-filter frame per immutable record and charges its possible frame/cache-cell reservation within the unchanged 2 MiB retained-ring budget; other filters, signed checkpoints and epoch/reset boundaries remain independent.
`native_api/events/http.rs` owns event query/cursor parsing, Accept negotiation and HTTP stream responses shared with logs; replay, signing, subscriptions and frame-budget accounting remain in `native_api/events.rs`.

### Logs

Clash `/logs` (`clash_api/logs.rs`) skips formatting without subscribers; its unfiltered tracing layer would otherwise allocate a `String` per sub-level datapath event. Default logs silence `quinn::endpoint` (`logging.rs::QUIET_TARGET`): its driver-death ERROR accompanies carrier loss under probe/warm transports (e.g. SYNACK-watchdog kills) and duplicates the failure honk reports with its own context, so it is lifecycle noise. A completed nonzero-timeout packet-backed endpoint close stops Quinn drivers before adapter workers and emits none; zero-timeout close and parent-owner teardown keep their existing order. Valid `RUST_LOG` overrides console/file filtering until a native `log.level` PATCH, which the next activation reverts; Clash `/logs` and native `/api/v1/logs` always exclude this target.
