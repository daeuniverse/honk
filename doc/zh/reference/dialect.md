# honk 的 dae 配置方言

honk 使用 dae 配置语法的一个方言。同一段文本在两者中解析结果不同时，以 honk 文档规定的行为为准。下表列出 honk 解析器当前对源文本的处理规则；dae 一栏只描述 dae 的文法 `dae_config.g4`，不涉及值转换。

## 词法规则

| 输入 | dae 文法 | honk | 案例 |
|---|---|---|---|
| 裸值内的 `#`，如 `log_file: /tmp/a#b`、`use_host: /tmp/a#b` 或 `group(hk#suffix)` | `#` 是裸字面量内的安全字符 | 紧贴前文的 `#` 按数据处理，并在旧版会截断的位置产生 `legacy-glued-hash` warning。标量路径仍是 `/tmp/a#b`，子组名是 `hk#suffix`。要写注释，就在 `#` 前加空白。 | [dialect-lexical-01-scalar-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-01-scalar-hash.dae), [dialect-lexical-01-host-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-01-host-hash.dae), [dialect-lexical-01-group-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-01-group-hash.dae) |
| 路由规则里紧贴出站名的 `#`，`domain(x) -> proxy#c` | 一个裸字面量 `proxy#c` | 字面目标就是 `proxy#c`，会产生 `legacy-glued-hash` warning，之后仍要通过常规的目标校验。注释写成 `-> proxy # comment`。 | [dialect-lexical-02-outbound-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-02-outbound-hash.dae) |
| `/* … */` | 块注释，跳过 | 不支持块注释。以 `/*` 开头的语句会产生 `unsupported-comment` warning 并被忽略，后面的物理行仍按配置读取。要写多行注释，每行都用 `#`。 | [dialect-lexical-03-block-comment](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-03-block-comment.dae) |
| 声明后的 `[key: value]`，`filter: name(x) [add_latency: -500ms]` | 作为注解接受 | 不识别。这个过滤条件会报为无法解析并忽略。honk 不支持按节点加延迟偏置。 | [dialect-lexical-04-annotation](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-04-annotation.dae) |
| 裸标量内的撇号，如 `log_file: /tmp/don't`，或已开启的流量参数引号 | 裸值内的撇号是词法错误 | `/tmp/don't` 按字面值读取。引号只在词法单元开头，或紧接引号外的 `(`、`,`、`:` 时才开始，所以 `key:'value'` 和 `key: 'value'` 是同一条目。顶层 `include` 还会识别相邻的带引号路径。流量规则里的引号如果不在同一物理行闭合，会产生带位置的 `unterminated-quote` 错误，所以要闭合引号，不要靠花括号恢复结构。 | [dialect-lexical-05-apostrophe](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-05-apostrophe.dae), [dialect-lexical-05-unterminated](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-05-unterminated.dae), [dialect-lexical-05-quote-after-colon](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-05-quote-after-colon.dae) |
| 引号或注释内的花括号，如 `secret: 'a}b'` | 数据 | 引号内和词法单元开头注释内的花括号都按数据处理。matcher 参数或 User-Agent 后缀里紧凑的 `{}` 也是数据；分开且未加引号的 `{` 和 `}` 仍是结构符号。条目尾部紧贴 `#` 的兼容截断，不会连单独的结构花括号一起截掉。旧版对注释内花括号的解释发生变化时，会产生 `legacy-comment-brace` warning。真正的右花括号必须写在注释外。 | [dialect-lexical-06-quoted-brace](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-quoted-brace.dae), [dialect-lexical-06-comment-brace](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-comment-brace.dae), [dialect-lexical-06-compact-argument](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-compact-argument.dae), [dialect-lexical-06-ua-brace](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-ua-brace.dae) |
| 块起始符前没有空格，`global{ … }` | 空白被跳过，仍是块 | 块头和花括号之间没有空白时，不管块在行内还是行尾，都会报 `block-delimiter-spacing` 错误。块头和花括号之间要留空白。`global {}` 这样的紧凑空块仍然可以，`group { a {} b {} }` 里相邻的声明也仍是独立块。 | [dialect-lexical-07-glued-opener](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-07-glued-opener.dae), [dialect-lexical-07-compact-empty](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-07-compact-empty.dae), [dialect-lexical-07-adjacent-groups](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-07-adjacent-groups.dae) |
| 多余的 `}`，或空文件 | 多余的 `}` 被拒绝；空输入或只有注释的输入被接受 | 多余的右花括号会产生 `unmatched-close` warning 并被忽略。不含块的 dae 入口文档或独立字符串文档会被拒绝，被包含的空文件或纯注释 `.dae` 片段则不贡献配置段。多余右花括号的兼容行为留到首次 PR2 发布后再评估。 | [dialect-lexical-08-extra-closer](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-08-extra-closer.dae), [dialect-lexical-08-empty](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-08-empty.dae), [dialect-lexical-08-comment-only](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-08-comment-only.dae) |
| 代理组名，`123 {`、`香港 {`、`Hong Kong {` | 块名必须是一个 `ID` | 和 `{` 分开写的原始块头就是动态组名。未知顶层名称会产生诊断并被跳过，不会当成插件加载。 | [dialect-lexical-09-numeric](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-09-numeric.dae), [dialect-lexical-09-unicode](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-09-unicode.dae), [dialect-lexical-09-spaces](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-09-spaces.dae) |
| 一行两个声明，`global { log_level: debug log_file: x }` | 空白分隔的两个声明 | honk 读成一个声明：`log_level` 的值是 `debug log_file: x`。每个 `key: value` 占一行，单行块只能放一条语句。 | [dialect-lexical-10-same-line](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-10-same-line.dae) |
| 起始花括号另起一行，`global` 换行 `{` | 空白包括换行在内都会被跳过 | 普通块的起始花括号不能另起一行。只有顶层 `include` 还保留这种兼容写法，中间允许有空行或注释行，并产生带位置的 `legacy-include-opener` warning。把 `{` 写在 `include` 块头那一行。这项兼容行为留到首次 PR2 发布后再评估。 | [dialect-lexical-11-split-root](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-11-split-root.dae), [dialect-lexical-11-split-include](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-11-split-include.dae) |

## 标量与列表

| 输入 | dae 文法 | honk | 案例 |
|---|---|---|---|
| 带冒号的裸值，`bind: 127.0.0.1:53` | 不是一个字面量，必须加引号 | 接受不加引号的写法：值是第一个 `:` 之后的全部文本。 | [dialect-scalars-01-bare-colons](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-01-bare-colons.dae) |
| 调用形态的值，`client_subnet: auto(9.9.9.9)` | 函数表达式 | 整段文本 `auto(9.9.9.9)` 就是值，由该设置自己解析。 | [dialect-scalars-02-call-value](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-02-call-value.dae) |
| 带引号的列表项，`lan_interface: 'eth0', 'eth1'` | 两个字面量 | 先按逗号拆分列表，再去掉每一项外面的一对引号，结果是 `eth0`、`eth1`。某种引号写法如果在旧版中解析结果不同，会产生 `legacy-list-quoting` warning；`native_api` 的列表在旧版没有别的读法，所以不会产生。检查目标列表仍接受整体加引号的逗号列表，并产生 `legacy-quoted-list` warning；建议逐项加引号，或者干脆不加引号。 | [dialect-scalars-03-list](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-03-list.dae), [dialect-scalars-03-aggregate](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-03-aggregate.dae) |
| 布尔值 `t`、`y`、`f`、`n` | 裸字面量 | 宽松设置按不区分大小写读取：`true`、`yes`、`1`、`on` 为真，`false`、`f`、`no`、`n`、`0`、`off`、`t`、`y` 为假。四种单字母简写会产生 `legacy-bool-shorthand` warning；无法识别的写法按假处理并报告诊断。建议写 `true` 或 `false`。以下设置使用严格解析：`global.nfqueue_enable`、`global.shutdown_wait_connections`、`global.syslog_dns_enabled`、`global.syslog_cee_enabled`、旧版 `experimental.udp_nfqueue.enabled`、所有 `experimental.native_api` 布尔字段，以及组的 `interrupt_connections`。严格设置只接受不区分大小写的 `true`/`false`、`yes`/`no`、`1`/`0` 和 `on`/`off`；简写或拼错会让配置被拒绝。 | [dialect-scalars-04-t](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-t.dae), [dialect-scalars-04-y](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-y.dae), [dialect-scalars-04-f](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-f.dae), [dialect-scalars-04-n](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-n.dae), [dialect-scalars-04-strict](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-strict.dae) |
| 订阅或 `assets.subscription` 中无效的 `cache`，如 `cache: typo` | 裸字面量 | 使用严格词表，但无效值会产生 warning 并回退为 `true`。无效的 `assets.geodata.auto_update` 和 `assets.geodata.checksum` 会产生 warning 并被忽略。 | |
| mark，`so_mark_from_dae: 0x10` 与 `so_mark_from_dae: 10` | 裸字面量 | 两种写法都按十六进制读取，结果都是 16。无法解析的 mark 会回退为 0 并报告诊断。 | [dialect-scalars-05-0x10](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-05-0x10.dae), [dialect-scalars-05-10](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-05-10.dae), [dialect-scalars-05-zz](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-05-zz.dae) |
| 毫秒设置里的小数秒，`check_tolerance: 1.5s` | 裸字面量 | 结果为 1500 毫秒。毫秒时长无法解析时，例如 `check_tolerance`、`sniffing_timeout`，会回退到该设置的默认值并报告诊断。秒时长无法解析时，例如 `check_interval`、订阅 `interval`，会回退为 `0` 并报告诊断，随后校验用 `check_interval must be a positive duration` 拒绝 `check_interval: 0`。 | [dialect-scalars-06-1-5s](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-06-1-5s.dae), [dialect-scalars-06-never](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-06-never.dae), [dialect-scalars-06-seconds](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-06-seconds.dae) |
| `fixed_domain_ttl` 条目 `x: 60#note`、`y: '60'`、`z: 60 ignored` | `60#note` 与 `'60'` 是字面量，`60 ignored` 是两个词法单元 | 值必须正好是一个十进制标量。`y` 存为 60，并产生 `legacy-ttl-quoting`；`x` 因 `invalid-ttl` 被省略，`z` 因 `trailing-value` 被省略。写 `60` 或带引号的 `60`，说明文字放在 ` # ` 后面。 | [dialect-scalars-07-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-07-hash.dae), [dialect-scalars-07-quoted](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-07-quoted.dae), [dialect-scalars-07-trailing](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-07-trailing.dae) |
| 未知的 `policy`，`policy: mystery(...)` | 任意函数表达式 | 回退为 `selector` 并报告诊断；参数文本不会被回显。 | [dialect-scalars-08-unknown-policy](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-08-unknown-policy.dae) |

## node 与 subscription 条目

| 输入 | dae 文法 | honk | 案例 |
|---|---|---|---|
| 分享链接或订阅上的标签 | `ID ':' literal`；裸字面量不能含 `:`，所以链接要加引号 | 条目头不加引号时，第一个 `:` 之前的文本就是标签，除非这个冒号是 `://` 的开头。条目头加引号时，只有闭引号后紧跟 `:` 才声明标签；因此未加引号的 User-Agent 或注释后缀里的冒号只是后缀数据。链接可以不加引号，标签和链接也都可以加引号。只有 `subscription` 允许整体加引号、标签在引号内的值，例如 `'paid:https://…'`，会先去掉引号再拆分；没有标签的条目以 URL 主机名命名。`node` 中加引号的值就是整个链接，所以 `'paid:socks5://…'` 会被当作未知协议。 | [dialect-entries-01-tagged](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-tagged.dae), [dialect-entries-01-bare](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-bare.dae), [dialect-entries-01-quoted-tag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-quoted-tag.dae), [dialect-entries-01-embedded-subtag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-embedded-subtag.dae), [dialect-entries-01-embedded-nodetag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-embedded-nodetag.dae), [dialect-entries-01-tagless](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-tagless.dae) |
| 条目行的行尾注释 | `#` 作为词法单元开头时是注释 | `#` 前面是空格或制表符时，会结束该行。值内部紧贴前文的 `#` 仍是数据，例如 `…#hk1`、`?filter='hk'#token`、`/tmp/a#b`。节点或链接的结束引号之后，或订阅完整的 `(UA)` 后缀之后，紧贴的 `#` 会以 `legacy-glued-hash` warning 截断条目尾部，但它不是词法注释，后面单独出现的大括号仍会改变块结构。写注释时，`#` 要用空白与前文隔开。其他尾随文本会让条目被跳过，并产生 `trailing-entry-text` 或 `legacy-ua-boundary` 诊断。 | [dialect-entries-02-comment](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-02-comment.dae), [dialect-entries-02-glued](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-02-glued.dae), [dialect-entries-02-trailing](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-02-trailing.dae) |
| 订阅链接后的 `'url'(User-Agent)` | 不在文法内 | honk 扩展：括号里的文本是 User-Agent。括号内的 User-Agent 不加引号时，前面有空格的 `#` 会结束该行，所以这类 User-Agent 要加引号。 | [dialect-entries-03-user-agent](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-03-user-agent.dae), [dialect-entries-03-quoted-agent](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-03-quoted-agent.dae), [dialect-entries-03-unquoted-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-03-unquoted-hash.dae) |
| 订阅块：`paid: {` 之后各占一行的 `url: …`、`ua: …`、`interval: …` 与 `}` | `ID ':' '{'` 不是声明 | honk 扩展：订阅也可以写成块，设置和其他块一样每行一条。 | [dialect-entries-04-block](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-04-block.dae) |
| 带引号的订阅链接后接块：`paid: 'url' {` 之后各占一行的 `ua: …`、`interval: …`、`cache: …` 或 `route: …` 与 `}` | `ID ':' literal` 已结束声明 | honk 扩展：条目选项，未设置的项取 `assets.subscription` 和 `assets.route`。`route` 取代旧块形式里的 `download_detour`；两者同时设置会报 `conflicting-subscription-route`。 | |
| `node` 里冒号前带空格的裸标签，`edge : 'socks5://…'` | 标签为 `edge` | 冒号两侧的空白会被规范化：节点保留下来，标签为 `edge`，并产生 `entry-tag-normalized` 信息级诊断。`edge: …` 和带引号的标签也仍然接受。 | [dialect-entries-05-spaced-tag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-05-spaced-tag.dae) |
| VLESS 分享链接或扁平序列化 VLESS 节点中的 `vless_mode` | 旧 VLESS mode 选择器 | 已移除，不接受为别名。分享链接要改用独立的 `udp=`、`packetEncoding=` 和 `mux=` query 参数。扁平 VLESS 节点拒绝任何形式的 `vless_mode`，包括 `null`，请改用 `network`、`packet_encoding` 和 `multiplex`。 | |
| 扁平序列化非 VLESS 节点上的 `vless_mode: legacy` | VLESS 之外的旧字段 | 这只是序列化适配器读写用的兼容占位字段，不影响行为。它是非 VLESS 序列化中唯一的例外，不属于文档支持的 dae 语法或分享链接语法。 | |

## 路由

| 输入 | dae 文法 | honk | 案例 |
|---|---|---|---|
| 裸前缀 matcher，`!geosite:cn -> proxy`、`domain:example.com -> proxy` | 不是函数调用，拒绝 | 接受为 matcher，前缀可以是 `geosite`、`geoip`、`domain`、`suffix`、`keyword`、`regex` 或 `full`。 | [dialect-routing-01-geosite-prefix](../../../crates/honk-config/conformance/cases/dialect/dialect-routing-01-geosite-prefix.dae), [dialect-routing-01-domain-prefix](../../../crates/honk-config/conformance/cases/dialect/dialect-routing-01-domain-prefix.dae) |
| 两个箭头，`domain(x) -> proxy->backup` | 拒绝 | 出站名就是字面文本 `proxy->backup`，并产生 `legacy-arrow-target` warning。这种兼容写法保留下来，但仍要通过常规的目标校验。 | [dialect-routing-02-two-arrows](../../../crates/honk-config/conformance/cases/dialect/dialect-routing-02-two-arrows.dae) |
| `-> proxy( must )` | 带参数 `must` 的调用 | 非 direct 目标仍要求后缀正好是 `(must)`；`proxy( must )` 会被当成名叫 `proxy( must )` 的出站。direct 会解析选项列表，所以 `direct( must )` 是终局规则。 | [dialect-routing-03-spaced-must](../../../crates/honk-config/conformance/cases/dialect/dialect-routing-03-spaced-must.dae), [直连选项测试](../../../crates/honk-config/tests/parser_syntax.rs) |
