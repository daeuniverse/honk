# honk 的 dae 設定方言

honk 使用 dae 設定語法的一個方言。同一段文字在兩者中解析結果不同時，以 honk 文件規定的行為為準。下表列出 honk 解析器目前對原始文字的處理規則；dae 一欄只描述 dae 的文法 `dae_config.g4`，不涉及值轉換。

## 語彙規則

| 輸入 | dae 文法 | honk | 案例 |
|---|---|---|---|
| 裸值內的 `#`，如 `log_file: /tmp/a#b`、`use_host: /tmp/a#b` 或 `group(hk#suffix)` | `#` 是裸字面值內的安全字元 | 緊貼前文的 `#` 視為資料，並在舊版會截斷的位置產生 `legacy-glued-hash` warning。純量路徑仍是 `/tmp/a#b`，子群組名稱是 `hk#suffix`。要寫註解，就在 `#` 前加空白。 | [dialect-lexical-01-scalar-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-01-scalar-hash.dae), [dialect-lexical-01-host-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-01-host-hash.dae), [dialect-lexical-01-group-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-01-group-hash.dae) |
| 路由規則裡緊貼出站名稱的 `#`，`domain(x) -> proxy#c` | 一個裸字面值 `proxy#c` | 字面目標就是 `proxy#c`，會產生 `legacy-glued-hash` warning，之後仍要通過一般的目標驗證。註解寫成 `-> proxy # comment`。 | [dialect-lexical-02-outbound-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-02-outbound-hash.dae) |
| `/* … */` | 區塊註解，跳過 | 不支援區塊註解。以 `/*` 開頭的語句會產生 `unsupported-comment` warning 並被忽略，後面的實體行仍照設定讀取。要寫多行註解，每行都用 `#`。 | [dialect-lexical-03-block-comment](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-03-block-comment.dae) |
| 宣告後的 `[key: value]`，`filter: name(x) [add_latency: -500ms]` | 視為註記接受 | 不識別。這個過濾條件會回報為無法解析並忽略。honk 不支援為個別節點加上延遲偏移。 | [dialect-lexical-04-annotation](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-04-annotation.dae) |
| 裸純量內的撇號，如 `log_file: /tmp/don't`，或流量引數中已開啟的引號 | 裸值內的撇號是語彙錯誤 | `/tmp/don't` 按字面值讀取。引號只在 token 開頭，或緊接引號外的 `(`、`,`、`:` 時才開始，所以 `key:'value'` 和 `key: 'value'` 是同一筆條目。頂層 `include` 還會識別相鄰的帶引號路徑。流量規則裡的引號如果不在同一實體行閉合，會產生帶位置的 `unterminated-quote` 錯誤，所以要閉合引號，不要靠大括號恢復結構。 | [dialect-lexical-05-apostrophe](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-05-apostrophe.dae), [dialect-lexical-05-unterminated](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-05-unterminated.dae), [dialect-lexical-05-quote-after-colon](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-05-quote-after-colon.dae) |
| 引號或註解內的大括號，如 `secret: 'a}b'` | 資料 | 引號內和 token 開頭註解內的大括號都視為資料。matcher 引數或 User-Agent 字尾裡緊湊的 `{}` 也是資料；分開且未加引號的 `{` 和 `}` 仍是結構符號。條目尾端緊貼 `#` 的相容截斷，不會連單獨的結構大括號一起截掉。舊版對註解內大括號的解釋發生變化時，會產生 `legacy-comment-brace` warning。真正的右大括號必須寫在註解外。 | [dialect-lexical-06-quoted-brace](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-quoted-brace.dae), [dialect-lexical-06-comment-brace](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-comment-brace.dae), [dialect-lexical-06-compact-argument](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-compact-argument.dae), [dialect-lexical-06-ua-brace](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-06-ua-brace.dae) |
| 區塊起始符前沒有空格，`global{ … }` | 空白被跳過，仍是區塊 | 區塊標頭和大括號之間沒有空白時，不管區塊在行內還是行尾，都會回報 `block-delimiter-spacing` 錯誤。區塊標頭和大括號之間要留空白。`global {}` 這樣的緊湊空區塊仍然可以，`group { a {} b {} }` 裡相鄰的宣告也仍是獨立區塊。 | [dialect-lexical-07-glued-opener](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-07-glued-opener.dae), [dialect-lexical-07-compact-empty](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-07-compact-empty.dae), [dialect-lexical-07-adjacent-groups](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-07-adjacent-groups.dae) |
| 多餘的 `}`，或空檔案 | 多餘的 `}` 被拒絕；空輸入或只有註解的輸入被接受 | 多餘的右大括號會產生 `unmatched-close` warning 並被忽略。不含區塊的 dae 入口文件或獨立字串文件會被拒絕，被包含的空檔案或純註解 `.dae` 片段則不貢獻設定區段。多餘右大括號的相容行為留到首次 PR2 發布後再評估。 | [dialect-lexical-08-extra-closer](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-08-extra-closer.dae), [dialect-lexical-08-empty](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-08-empty.dae), [dialect-lexical-08-comment-only](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-08-comment-only.dae) |
| 代理群組名稱，`123 {`、`香港 {`、`Hong Kong {` | 區塊名稱必須是一個 `ID` | 和 `{` 分開寫的原始區塊標頭就是動態群組名稱。未知的頂層名稱會產生診斷並被跳過，不會當成外掛載入。 | [dialect-lexical-09-numeric](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-09-numeric.dae), [dialect-lexical-09-unicode](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-09-unicode.dae), [dialect-lexical-09-spaces](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-09-spaces.dae) |
| 一行兩個宣告，`global { log_level: debug log_file: x }` | 以空白分隔的兩個宣告 | honk 讀成一個宣告：`log_level` 的值是 `debug log_file: x`。每個 `key: value` 佔一行，單行區塊只能放一條語句。 | [dialect-lexical-10-same-line](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-10-same-line.dae) |
| 起始大括號另起一行，`global` 換行 `{` | 空白（包括換行）都會被跳過 | 一般區塊的起始大括號不能另起一行。只有頂層 `include` 還保留這種相容寫法，中間允許有空行或註解行，並產生帶位置的 `legacy-include-opener` warning。把 `{` 寫在 `include` 區塊標頭那一行。這項相容行為留到首次 PR2 發布後再評估。 | [dialect-lexical-11-split-root](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-11-split-root.dae), [dialect-lexical-11-split-include](../../../crates/honk-config/conformance/cases/dialect/dialect-lexical-11-split-include.dae) |

## 純量與清單

| 輸入 | dae 文法 | honk | 案例 |
|---|---|---|---|
| 帶冒號的裸值，`bind: 127.0.0.1:53` | 不是單一字面值，必須加引號 | 接受不加引號的寫法：值是第一個 `:` 之後的全部文字。 | [dialect-scalars-01-bare-colons](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-01-bare-colons.dae) |
| 呼叫形態的值，`client_subnet: auto(9.9.9.9)` | 函式運算式 | 整段文字 `auto(9.9.9.9)` 就是值，由該設定自行解析。 | [dialect-scalars-02-call-value](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-02-call-value.dae) |
| 帶引號的清單項，`lan_interface: 'eth0', 'eth1'` | 兩個字面值 | 先按逗號分割清單，再去掉每一項外面的一對引號，結果是 `eth0`、`eth1`。某種引號寫法如果在舊版中解析結果不同，會產生 `legacy-list-quoting` warning；`native_api` 的清單在舊版沒有別的讀法，所以不會產生。檢查目標清單仍接受整體加引號的逗號清單，並產生 `legacy-quoted-list` warning；建議逐項加引號，或全部不加引號。 | [dialect-scalars-03-list](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-03-list.dae), [dialect-scalars-03-aggregate](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-03-aggregate.dae) |
| 布林值 `t`、`y`、`f`、`n` | 裸字面值 | 寬鬆設定按不區分大小寫讀取：`true`、`yes`、`1`、`on` 為真，`false`、`f`、`no`、`n`、`0`、`off`、`t`、`y` 為假。四種單字母簡寫會產生 `legacy-bool-shorthand` warning；無法識別的寫法視為假並回報診斷。建議寫 `true` 或 `false`。以下設定使用嚴格解析：`global.nfqueue_enable`、`global.shutdown_wait_connections`、`global.syslog_dns_enabled`、`global.syslog_cee_enabled`、舊版 `experimental.udp_nfqueue.enabled`、所有 `experimental.native_api` 布林欄位，以及群組的 `interrupt_connections`。嚴格設定只接受不區分大小寫的 `true`/`false`、`yes`/`no`、`1`/`0` 和 `on`/`off`；簡寫或拼錯會使設定遭拒。 | [dialect-scalars-04-t](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-t.dae), [dialect-scalars-04-y](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-y.dae), [dialect-scalars-04-f](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-f.dae), [dialect-scalars-04-n](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-n.dae), [dialect-scalars-04-strict](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-04-strict.dae) |
| 訂閱或 `assets.subscription` 中無效的 `cache`，如 `cache: typo` | 裸字面值 | 使用嚴格詞彙表，但無效值會產生 warning 並退回 `true`。無效的 `assets.geodata.auto_update` 和 `assets.geodata.checksum` 會產生 warning 並被忽略。 | |
| mark，`so_mark_from_dae: 0x10` 與 `so_mark_from_dae: 10` | 裸字面值 | 兩種寫法都按十六進位讀取，結果都是 16。無法解析的 mark 會退回 0 並回報診斷。 | [dialect-scalars-05-0x10](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-05-0x10.dae), [dialect-scalars-05-10](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-05-10.dae), [dialect-scalars-05-zz](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-05-zz.dae) |
| 毫秒設定裡的小數秒，`check_tolerance: 1.5s` | 裸字面值 | 結果為 1500 毫秒。以毫秒計的持續時間無法解析時，例如 `check_tolerance`、`sniffing_timeout`，會退回該設定的預設值並回報診斷。以秒計的持續時間無法解析時，例如 `check_interval`、訂閱 `interval`，會退回 `0` 並回報診斷，隨後驗證以 `check_interval must be a positive duration` 拒絕 `check_interval: 0`。 | [dialect-scalars-06-1-5s](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-06-1-5s.dae), [dialect-scalars-06-never](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-06-never.dae), [dialect-scalars-06-seconds](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-06-seconds.dae) |

| 未知的 `policy`，`policy: mystery(...)` | 任意函式運算式 | 退回 `selector` 並回報診斷；引數文字不會被回顯。 | [dialect-scalars-08-unknown-policy](../../../crates/honk-config/conformance/cases/dialect/dialect-scalars-08-unknown-policy.dae) |

## node 與 subscription 條目

| 輸入 | dae 文法 | honk | 案例 |
|---|---|---|---|
| 分享連結或訂閱上的標籤 | `ID ':' literal`；裸字面值不能含 `:`，所以連結要加引號 | 條目開頭不加引號時，第一個 `:` 之前的文字就是標籤，除非這個冒號是 `://` 的開頭。條目開頭加引號時，只有閉引號後緊跟 `:` 才宣告標籤；因此未加引號的 User-Agent 或註解字尾裡的冒號只是字尾資料。連結可以不加引號，標籤和連結也都可以加引號。只有 `subscription` 允許整體加引號、標籤在引號內的值，例如 `'paid:https://…'`，會先去掉引號再分割；沒有標籤的條目以 URL 主機名稱命名。`node` 中加引號的值就是整個連結，所以 `'paid:socks5://…'` 會被當作未知協定。 | [dialect-entries-01-tagged](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-tagged.dae), [dialect-entries-01-bare](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-bare.dae), [dialect-entries-01-quoted-tag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-quoted-tag.dae), [dialect-entries-01-embedded-subtag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-embedded-subtag.dae), [dialect-entries-01-embedded-nodetag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-embedded-nodetag.dae), [dialect-entries-01-tagless](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-01-tagless.dae) |
| 條目行的行尾註解 | `#` 作為 token 開頭時是註解 | `#` 前面是空格或定位字元時，會結束該行。值內部緊貼前文的 `#` 仍是資料，例如 `…#hk1`、`?filter='hk'#token`、`/tmp/a#b`。節點或連結的結束引號之後，或訂閱完整的 `(UA)` 字尾之後，緊貼的 `#` 會以 `legacy-glued-hash` warning 截斷條目尾端，但它不是語彙註解，後面單獨出現的大括號仍會改變區塊結構。寫註解時，`#` 要用空白與前文隔開。其他尾隨文字會讓條目被跳過，並產生 `trailing-entry-text` 或 `legacy-ua-boundary` 診斷。 | [dialect-entries-02-comment](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-02-comment.dae), [dialect-entries-02-glued](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-02-glued.dae), [dialect-entries-02-trailing](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-02-trailing.dae) |
| 訂閱連結後的 `'url'(User-Agent)` | 不在文法內 | honk 擴充：括號裡的文字是 User-Agent。括號內的 User-Agent 不加引號時，前面有空格的 `#` 會結束該行，所以這類 User-Agent 要加引號。 | [dialect-entries-03-user-agent](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-03-user-agent.dae), [dialect-entries-03-quoted-agent](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-03-quoted-agent.dae), [dialect-entries-03-unquoted-hash](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-03-unquoted-hash.dae) |
| 訂閱區塊：`paid: {` 之後各佔一行的 `url: …`、`ua: …`、`interval: …` 與 `}` | `ID ':' '{'` 不是宣告 | honk 擴充：訂閱也可以寫成區塊，設定和其他區塊一樣每行一條。 | [dialect-entries-04-block](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-04-block.dae) |
| 帶引號的訂閱連結後接區塊：`paid: 'url' {` 之後各佔一行的 `ua: …`、`interval: …`、`cache: …` 或 `route: …` 與 `}` | `ID ':' literal` 已結束宣告 | honk 擴充：條目選項，未設定的項取自 `assets.subscription` 和 `assets.route`。`route` 取代舊區塊形式裡的 `download_detour`；兩者同時設定會回報 `conflicting-subscription-route`。 | |
| `node` 裡冒號前帶空格的裸標籤，`edge : 'socks5://…'` | 標籤為 `edge` | 冒號兩側的空白會被正規化：節點保留下來，標籤為 `edge`，並產生 `entry-tag-normalized` 資訊等級診斷。`edge: …` 和帶引號的標籤也仍然接受。 | [dialect-entries-05-spaced-tag](../../../crates/honk-config/conformance/cases/dialect/dialect-entries-05-spaced-tag.dae) |
| VLESS 分享連結或扁平序列化 VLESS 節點中的 `vless_mode` | 舊 VLESS mode 選擇器 | 已移除，不接受為別名。分享連結要改用獨立的 `udp=`、`packetEncoding=` 和 `mux=` query 引數。扁平 VLESS 節點拒絕任何形式的 `vless_mode`，包括 `null`，請改用 `network`、`packet_encoding` 和 `multiplex`。 | |
| 扁平序列化非 VLESS 節點上的 `vless_mode: legacy` | VLESS 之外的舊欄位 | 這只是序列化配接器讀寫用的相容佔位欄位，不影響行為。它是非 VLESS 序列化中唯一的例外，不屬於文件支援的 dae 語法或分享連結語法。 | |

## 路由

| 輸入 | dae 文法 | honk | 案例 |
|---|---|---|---|
