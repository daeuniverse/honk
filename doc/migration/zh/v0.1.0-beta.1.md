# 迁移到 v0.1.0-beta.1

适用于从 `v0.0.1.beta.84` 或更早版本升级的配置，仅列出影响已有配置文件的变更。
各版本的迁移说明与本文件并列存放。

## 1. 升级前必读

| 变更 | 处理方式 |
| --- | --- |
| 运行状态改存 `<data_dir>/state/honk.db`，不再使用 `cache.db`。 | 无需操作。首次启动会导入旧 `cache.db`（按配置的 `cache_id` 前缀），`cache_id` 为空时随后删除它。 |
| `cache_file.enabled` 语义变化：未写 = 保留 Selector 选择与延迟样本；`true` = 额外持久化 Clash mode 与 GLOBAL 选择，并允许 `store_dns`；`false` = 不保留任何运行时状态。 | 要保持旧的 mode 持久化行为，需显式写 `enabled: true`。 |
| 订阅正文缓存从 `<data_dir>/.sub` 移入状态数据库。 | 无需操作。首次启动会从第一个私有的旧 `.sub` 存储导入已启用订阅的正文。 |
| `experimental.cache_file.path`、`cache_id`、`store_fakeip` 不再生效。 | 建议删除。每次出现都会告警 `legacy-cache-file`；`path` 与 `cache_id` 仅供上述一次性导入读取。 |

`cache_file.enabled` 与 `store_dns` 仅在启动时生效，SIGHUP 修改会被拒绝。

## 2. 新增 `assets {}`

地理数据、面板 ZIP 与订阅的下载默认值从 `experimental` 移出。

```dae
assets {
    route: routing              # routing | direct | 分组名
    geodata {
        geosite: 'https://example.org/geosite.dat'
        geoip: 'https://example.org/geoip.dat'
        route: direct
    }
    ui { url: 'https://example.org/dashboard.zip' }
    subscription {
        ua: 'honk/<version>'
        interval: 86400s
        cache: true
    }
}
```

优先级：条目或子段显式值 → `assets` → 内置默认。旧键仍可解析，但会告警
`legacy-assets-key`；旧键与其替代键同时非空会导致启动失败（`conflicting-assets-setting`）。

| 旧键 | 新键 |
| --- | --- |
| `experimental.native_api.geosite_download_url` | `assets.geodata.geosite` |
| `experimental.native_api.geoip_download_url` | `assets.geodata.geoip` |
| `experimental.native_api.geodata_download_detour` | `assets.geodata.route` |
| `experimental.clash_api.external_ui_download_url` | `assets.ui.url` |
| `experimental.clash_api.external_ui_download_detour` | `assets.ui.route` |

只有 `.dae` 配置会解析 `assets`；JSON、YAML、TOML 直接存储解析后的下载字段，需在这些格式里
继续写 `experimental` 下的下载字段。

## 3. 新增 `experimental.native_api {}`（默认关闭）

启用原生 API 前，须以 `native-api` 或 `native-ui` 功能构建，否则启动失败。
示例中的内嵌界面需要 `native-ui`。所有字段仅在启动时生效，SIGHUP 修改会被拒绝。

```dae
experimental {
    native_api {
        enabled: true
        listen: '127.0.0.1:9527'
        secret: '<至少 16 字节的随机值>'
        ui: 'embedded'          # 或 embedded-lite / 受信任的本地目录；空 = 不托管 UI
    }
}
```

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `enabled` | `false` | 启动独立监听器。 |
| `listen` | `127.0.0.1:9527` | 数字 IP 加端口，不接受主机名。 |
| `secret` | `""` | 静态 Bearer 令牌；不能与 `password_auth` 同时使用。 |
| `password_auth` | `false` | 管理员密码登录；要求 `secret` 为空。 |
| `allow_anonymous_loopback` | `false` | 仅回环、无凭证访问；与 `password_auth` 互斥。 |
| `allow_origins`、`allowed_hosts` | 空 | 额外允许的 HTTP(S) 源与 Host，逐项加引号、逗号分隔。 |
| `ui` | `""` | `embedded` 或 `embedded-lite`（均需 `native-ui`；lite 是更轻量的 doona lite 预览版）或含 `index.html` 的本地目录。 |
| `record_flows`、`record_logs`、`record_dns_log` | `true` | 置 `false` 禁止相应诊断录制，需重启生效。 |
| `record_traffic`、`record_memory` | `true` | 保留 600 秒内最多 600 个样本；`false` 释放缓冲。 |
| `config_write` | `false` | 允许通过 API 替换整个配置源并重载；需令牌或密码模式。 |

启用原生 API 后，Clash 模式不再持久化：两套 API 共用一个临时模式，启动为 `Rule`。

## 4. 语法扩展（向后兼容）

**订阅**把 URL 写在条目行，选项放进其后的块：

```dae
subscription {
    detailed: 'https://example.org/sub' {
        ua: 'honk/1.0'
        interval: 10000s     # 0 = 关闭定时刷新
        cache: false
        route: direct        # 等价的旧名为 download_detour
    }
}
```

旧的 `tag: { url: ... }` 块与 `'URL'(UA)` 后缀仍可解析且不告警。`route` 与
`download_detour` 同时设置会报 `conflicting-subscription-route`。

**分组**新增 `icon`；`tolerance`、`idle_timeout`、`interrupt_connections` 现在在 dae 语法下
同样可用。`interrupt_connections: true` 会在选择变化时关闭受影响的存活传输，而不再只是取消跟踪。

## 5. 已移除的键

| 键 | 行为 |
| --- | --- |
| `probe_allowed_cidrs`、`probe_allowed_ports` | 各告警一次并被忽略，不再序列化。删除即可。 |

## 6. 无需改配置的行为变化

- **Shadowsocks**：未写 `encryption` 时按 `aes-128-gcm` 拨号。
- **DNS**：`max_cache_size` 上限为 100,000，且是唯一的缓存上限；独立的 wire-byte 预算已移除。
- **QUIC 出站**（Hysteria2、TUIC、Juicity）：连接窗口可增长到 32 MiB；发送 MTU 从 1200 起做
  路径探测，显式 `mtu` 会同时固定初始值与探测上界。
- **AnyTLS**：`min_idle_session` 的上限从两条会话变为八条。
- **CLI**：新增 `--store file|db`、`--data-dir PATH`、`config export` 与 `admin reset`。
  `--store db` 下不运行 Clash API，`external_controller` 非空会拒绝启动；`-c` 仅在库为空时导入。
- **环境变量**：`MIMALLOC_PURGE_DELAY` 默认 100 ms；`0` 立即归还，`-1` 从不归还。
