# Migrating to v0.1.0-beta.1

Use this page when upgrading a configuration from `v0.0.1.beta.84` or earlier.
It lists only changes that affect an existing configuration.

## 1. Before you upgrade

| Change | What to do |
| --- | --- |
| Runtime state moved to `<data_dir>/state/honk.db`; `cache.db` is gone. | Nothing. The first start imports the legacy `cache.db` (keys under the configured `cache_id`) and, with an empty `cache_id`, removes it afterwards. |
| `cache_file.enabled` changed meaning: unset keeps Selector choices and delay samples; `true` additionally persists the Clash mode and GLOBAL selection and allows `store_dns`; `false` keeps nothing. | Set `enabled: true` explicitly to keep the old mode persistence. |
| Subscription bodies moved from `<data_dir>/.sub` into the state db. | Nothing. The first start imports the enabled bodies from the first private legacy `.sub`. |
| `experimental.cache_file.path`, `cache_id` and `store_fakeip` no longer have any effect. | Delete them. Each occurrence logs `legacy-cache-file`; `path` and `cache_id` are read once for the import above. |

`cache_file.enabled` and `store_dns` are startup-owned; SIGHUP rejects a change to either.

## 2. New `assets {}` block

Download defaults (geodata, dashboard ZIP, subscriptions) moved out of `experimental`.

```dae
assets {
    route: routing              # routing | direct | group tag
    geodata {
        geosite: 'https://example.org/geosite.dat'
        geoip: 'https://example.org/geoip.dat'
        route: direct
    }
    ui { url: 'https://example.org/dashboard.zip' }
    subscription {
        ua: 'honk/<version>'
        interval: 86400s
        cache: true
    }
}
```

Values resolve as entry or sub-block, then `assets`, then the built-in default. The former
keys still parse but log `legacy-assets-key`; setting a legacy key and its replacement to
nonempty values fails startup with `conflicting-assets-setting`.

| Legacy setting | Replacement |
| --- | --- |
| `experimental.native_api.geosite_download_url` | `assets.geodata.geosite` |
| `experimental.native_api.geoip_download_url` | `assets.geodata.geoip` |
| `experimental.native_api.geodata_download_detour` | `assets.geodata.route` |
| `experimental.clash_api.external_ui_download_url` | `assets.ui.url` |
| `experimental.clash_api.external_ui_download_detour` | `assets.ui.route` |

Only `.dae` configurations resolve `assets`; JSON, YAML and TOML store the resolved download
fields, so set the `experimental` download fields directly in those formats.

## 3. New `experimental.native_api {}` block (off by default)

Build with `native-api` or `native-ui` before enabling the native API; otherwise startup fails.
The embedded UI in the example requires `native-ui`. Every field takes effect at startup;
SIGHUP rejects changes.

```dae
experimental {
    native_api {
        enabled: true
        listen: '127.0.0.1:9527'
        secret: '<random value of at least 16 bytes>'
        ui: 'embedded'          # or embedded-lite / a trusted local directory; empty disables hosting
    }
}
```

| Field | Default | Meaning |
| --- | --- | --- |
| `enabled` | `false` | Start the independent listener. |
| `listen` | `127.0.0.1:9527` | Numeric IP and port; no hostnames. |
| `secret` | `""` | Static bearer token; cannot be combined with `password_auth`. |
| `password_auth` | `false` | Administrator password login; requires an empty `secret`. |
| `allow_anonymous_loopback` | `false` | Credential-free loopback access; mutually exclusive with `password_auth`. |
| `allow_origins`, `allowed_hosts` | empty | Extra HTTP(S) origins and Host authorities, individually quoted and comma-separated. |
| `ui` | `""` | `embedded` or `embedded-lite` (both need `native-ui`; lite is the lighter doona lite edition, preview) or a local directory containing `index.html`. |
| `record_flows`, `record_logs`, `record_dns_log` | `true` | `false` prohibits the corresponding diagnostic capture; restart to change. |
| `record_traffic`, `record_memory` | `true` | Keep 600 samples over 600 seconds; `false` releases the buffer. |
| `config_write` | `false` | Allow whole-source replacement and reload through the API; needs token or password mode. |

With the native API enabled, the Clash mode is no longer persisted: both APIs share one
transient mode that starts at `Rule`.

## 4. Syntax additions (backward compatible)

**Subscriptions** put the URL on the entry line and options in a block after it:

```dae
subscription {
    detailed: 'https://example.org/sub' {
        ua: 'honk/1.0'
        interval: 10000s     # 0 disables periodic refresh
        cache: false
        route: direct        # alias: download_detour
    }
}
```

The older `tag: { url: ... }` block and the `'URL'(UA)` suffix still parse without a warning.
Setting both `route` and `download_detour` fails with `conflicting-subscription-route`.

**Groups** accept `icon`, and `tolerance`, `idle_timeout` and `interrupt_connections` now work
in dae syntax too. `interrupt_connections: true` closes the affected live transports on a
selection change; it is no longer just tracking removal.

## 5. Removed keys

| Key | Behavior |
| --- | --- |
| `probe_allowed_cidrs`, `probe_allowed_ports` | Each logs one warning and is ignored, never serialized. Delete it. |

## 6. Behavior changes that need no configuration edit

- Shadowsocks dials `aes-128-gcm` when `encryption` is omitted.
- DNS: `max_cache_size` is capped at 100,000 and is the only cache limit; the separate
  wire-byte budget is gone.
- QUIC outbounds (Hysteria2, TUIC, Juicity) grow the connection window up to 32 MiB and
  start the send MTU at 1200 with path-MTU discovery; an explicit `mtu` fixes both the
  initial value and the discovery bound.
- AnyTLS: `min_idle_session` is bounded by the eight-session pool instead of two.
- CLI: `--store file|db`, `--data-dir PATH`, `config export` and `admin reset` are new.
  `--store db` does not run the Clash API, so a nonempty `external_controller` refuses
  startup, and `-c` is imported only while the db is empty.
- Environment: `MIMALLOC_PURGE_DELAY` defaults to 100 ms; `0` purges immediately and
  `-1` never purges.
